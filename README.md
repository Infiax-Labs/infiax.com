# Infiax Labs

Building digital products with a focus on Sri Lankan and South Asian audiences.

## About

Infiax Labs is a small, independent software studio. We design and build apps, tools, and platforms aimed at solving real problems for local users — from entertainment and reading platforms to utility tools for everyday tasks.

## Flagship Project

### 📖 Katha Arana
A Flutter-based novel reading app supporting Sinhala and English, built with Riverpod and a Clean Architecture approach, backed by Supabase and Cloudflare R2 for storage.

- Cross-platform (Android-first)
- Offline-friendly reading experience
- Community-driven content

## Other Work

- **Browser extensions** — tools for comparing exchange rates and tracking financial data relevant to Sri Lankan users
- **Automation & bots** — Telegram bot integrations and cPanel-based deployment pipelines
- **Utility apps** — lightweight desktop tools for everyday maintenance tasks

## Tech Stack

`Flutter` · `Python` · `PHP` · `JavaScript` · `Supabase` · `Cloudflare R2` · `cPanel`
